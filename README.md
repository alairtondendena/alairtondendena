### Selected work

Extracted the rewards domain from a Scala/ZIO monolith into Kotlin/Spring Boot, added Kafka + DLQ to carrier integrations, migrated ECS → EKS, and helped build an AI onboarding agent (RAG, guardrails, human handover).
